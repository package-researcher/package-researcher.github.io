개인정보처리방침

최종 수정일: 2026년 10월 9일

이 사이트 운영자가 만든 업로드 도구(「썰백과 업로더」 등)는 운영자 본인의 유튜브 채널에 영상을 올리기 위한 개인용 프로그램입니다. 다른 사용자는 이 도구에 로그인하지 않습니다.

1. 사용하는 정보

  • Google 계정 로그인(OAuth)으로 받은 접근 권한: 운영자 본인 채널의 영상 업로드, 영상 정보·썸네일 수정
  • 그 외의 개인정보(이름, 연락처, 시청 기록 등)는 수집하지 않습니다.

2. 보관과 공유

  • 로그인 토큰은 운영자 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다.
  • 받은 정보를 제3자에게 팔거나 공유하지 않으며, 광고에 쓰지 않습니다.
  • Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 권한 철회

Google 계정 → 보안 → 타사 액세스에서 언제든 이 도구의 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

4. 유튜브 서비스 약관

이 도구는 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 문의

이 방침에 대한 문의는 Google Cloud 동의 화면에 적힌 개발자 연락처 이메일로 보내 주세요.
